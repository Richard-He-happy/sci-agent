# 适用场景
资料库类任务：把杂乱文件整理成可检索、可问答、可沉淀的知识库。

# 输入契约
- 资料目录（PDF/笔记/CSV/图片等）与任务要求（分类维度、问答题、需输出产物）
- 输出：目录结构/索引文件（JSONL/CSV）、分类结果、问答答案+证据、批注记录

# 流程
1. init：扫描文件树，记录路径/大小/哈希/mtime；识别重复
2. enrich：抽元数据（标题/作者/年份/DOI/主题/关键结论）写入索引
3. classify：按任务给定维度分类；不确定放 "unsorted" 并说明
4. answer：对每个问题给出答案 + 证据行（文件+定位）；无证据标"未验证"
5. persist：批注/修订/回执版本化（时间戳+diff），可回滚

# 关键检查
- 索引与真实文件 1:1（可重建）；不移动/覆盖原文件
- 分类可解释（维度+理由）；问答必带证据
- 重复文件去重记录来源；权限/敏感信息标注

# 常见失败
- 索引与文件不一致；改文件不记版本；问答无证据；分类维度混用；删原文件。
