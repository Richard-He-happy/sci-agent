# 适用场景
演示类任务：从论文/数据到可编辑 PPT（含模板适配），要求页级主张清晰、证据可定位、导出可校验。

# 输入契约
- 论文/材料、受众与时长、模板（或模板要求）、输出格式（pptx/pdf）
- 输出：pptx（可编辑）+ 讲稿要点（可选）+ 页面证据清单

# 流程
1. 提纲：一句话结论 → 3-5 条支撑 → 每页一个主张
2. 取证据：每页绑定原文定位（页码/图表号），数字与论文一致
3. 生成：统一版式（标题/字号/配色/页脚）；图表重绘用原始数据（不用截图糊）
4. 模板适配：母版/占位符/字体回退检查
5. 校验：打开无损坏、字体嵌入/回退、页数与字数、导出 PDF 一致性

# 关键检查
- 每页主张+证据；图表清晰（矢量优先）
- pptx 可解压、可编辑；无占位符残留
- 时长匹配（页/分钟）；关键结论在首尾呼应

# 常见失败
- 论文搬家式堆字；图表截图模糊；模板占位符未替换；字体缺失导致乱版；页数超时。
