# 科研工作台与评测工具

## 1. 用途

做两类"让科研流程可操作、可度量"的系统：

- **工作台/客户端**：阅读客户端（打开文献 → 定位 → 提问/批注 → 保存 → 回看 → 导出）与写作客户端（收稿 → 按工单局部修改 → 接受/拒绝 → 回执 → 版本回滚 → 导出）。
- **Benchmark/评测工具**：题卡、运行器、参考锚点、评分表、可追溯报告，让"某方法好在哪"可复算。

共同要求：**状态可持久化、操作可追溯、结果可复核、产物可编辑导出**。

不适用：单篇论文的一次性阅读（用 `sci-literature-reading`）；单次写作（用 `sci-academic-writing`）。

## 2. 阅读客户端：七步闭环

| 步骤 | 要做的事 | 产物 |
|---|---|---|
| 1 打开 | 载入文档，记录页数/标题/来源指纹 | `session.json` |
| 2 定位 | 段落/页码锚点（物理页与印刷页双记） | `anchors.json` |
| 3 选区提问 | 选中片段 → 提问 → 回答附 locator | `qa_log.jsonl` |
| 4 批注 | 批注/高亮挂锚点，不破坏原文 | `annotations.json` |
| 5 保存 | 会话状态落盘，可恢复 | 状态文件 |
| 6 回看 | 按锚点还原上下文（页码+段落） | 渲染检查 |
| 7 导出 | 批注/问答/摘要导出为可读文件 | `export.md` / `result.json` |

质量红线：锚点必须能回到原文；扫描件/坏 OCR 降级为 `partial` + `pending_human`；会话恢复后锚点不漂移。

## 3. 写作客户端：工单式修改

```text
收稿 → 解析工单（target/位置/要求）→ 逐条修改（accept / reject + 理由）
     → 生成回执（改了什么、依据、版本号）→ 支持 rollback → 导出差分
```

- 每次修改只动 target 范围，其余段落逐字保留；修改处带来源注记。
- 回执必须真实：`import / accept / reject / version / rollback` 五个动作实际发生，不伪造。
- 拒绝也要给理由；未做的修改明确标 `not_done`，不写在"已完成"里。
- 交付：修订稿 + 回执 + 版本历史 + 导出预览。

## 4. Benchmark / 评测工具

**题卡（tasks/cards）**：每题的输入、要求、可接受答案形态、评分维度。
**运行器**：可复算地跑被测方法，记录配置、版本、随机种子、输出。
**锚点（anchors）**：把主观标准写成"可观察现象"，例如"回答引用了原文第 3 节"。
**评分表（scores）**：逐题给分 + 理由 + 证据定位。
**报告**：汇总 + 失败类型分布 + 局限。

可追溯三指针（每个分数都要能追）：

```text
分数 → 题（task_id）→ 原始输出（run_id）→ 配置/版本（config）
```

- 评分规则写进题卡，不临场改；人工评分也记录评分人与依据。
- 合成/模拟的评测数据必须标注为"非真实分数"，不与真实评测混算。
- 报告中写清样本量、评测设置、已知偏差；不代表"全面优于"。

## 5. 通用质量红线

| 项 | 要求 |
|---|---|
| 状态持久化 | 会话/进度/版本写盘，崩溃后可恢复 |
| 操作可追溯 | 每次修改/评分有 id、时间、依据 |
| 可复现 | 同一输入、同一配置两次运行结果一致 |
| 导出 | 产物可被常见工具打开（或给出可解析的结构化文件） |
| 降级 | 解码失败/材料缺失时给出 partial + 缺口清单，不静默失败 |
| 隐私 | 不收集不必要个人信息；导出物中去除本地路径与账号信息 |

## 6. 自检清单

- [ ] 阅读客户端的锚点能回到原文；会话恢复后位置不漂移。
- [ ] 写作客户端只改 target，其余内容逐字保留；回执五动作真实发生。
- [ ] 评测运行器记录配置/种子/版本；同配置可复跑。
- [ ] 每个分数能追到"题→输出→配置"三指针。
- [ ] 合成数据已标注，不与真实评测混算。
- [ ] 导出文件可打开，且不含本地路径/账号等无关信息。

## 7. 示例（示例，非正式案例）

做一个"论文阅读批注 + 小结导出"小工作台：载入 PDF 后按段落记锚点，对 3 个结论做选区提问并保存问答记录，导出 `export.md`（结论 + locator + 原文引用）；再把它接进评测：用 10 条问题做小 Benchmark，运行器记录每题的问答输出与配置，评分表逐题给 0/1/2 分并写理由，报告给出通过率与失败类型，每个分数都能追到原始输出。

## 8. 边界

- 工作台不替代判断：批注/评分仍要人复核关键结论。
- 不为了"看起来完整"伪造操作记录、页码或评分依据。
- 文档解析（PDF/扫描件/OCR）质量决定上限；解析失败时如实降级。
