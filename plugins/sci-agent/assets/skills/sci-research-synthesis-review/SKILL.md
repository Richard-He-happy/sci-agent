# 适用场景
研究综合与审查类任务：综述生成、系统综述、趋势判断、选题评估、论文审查（质量/引用/方法统计/逻辑/合规）。

# 输入契约
- 研究问题/文献集/待审稿件；任务要求的输出结构（章节/评分/意见条数）
- 输出：综述文档或审查报告；每条判断带证据（文献引用或稿件定位）

# 流程
1. 建证据池：文献清单 + 关键结论 + 定位；去重、标质量等级
2. 综合：按主题聚合，呈现共识/分歧/空白；避免罗列式摘要
3. 审查（若为审查任务）：逐项核对（引用真实性、方法-统计匹配、论证链、合规），问题分级（必须修改/建议）
4. 结论：给可执行建议（补实验/补引用/改写段落），标明不确定性

# 关键检查
- 每条引用可核验（DOI/页码）；不虚构文献
- 综述有检索策略与纳排说明
- 审查意见具体到位置（页/段/行）

# 常见失败
- 综述=摘要拼接；引用不支持所引结论；审查意见空泛；漏掉关键反例；趋势判断无数据支撑。
