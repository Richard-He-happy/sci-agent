# 适用场景
分析类任务：从原始数据/数据库出发，完成清洗→统计→可视化→结论，要求可复现、可核验。

# 输入契约
- 数据文件/数据库连接/任务说明（指标、分组、统计方法、输出格式）
- 输出：清洗后数据、分析结果（表+指标）、图表文件、代码、result.json

# 流程
1. profile：行列数/类型/缺失/异常值/单位；记录数据哈希
2. clean：缺失值策略（删除/插补/标注）、去重、单位统一；每步写日志
3. analyze：按任务选方法（描述统计/t 检验/ANOVA/回归/相关），报告效应量与置信区间，不只报 p 值
4. visualize：坐标轴/单位/样本量/误差线明确；图注自含
5. build：代码可重跑（固定种子）、结果落盘、结论绑定证据

# 关键检查
- 方法与数据类型匹配；多重比较校正；不确定项标注
- 图表与数字一致（同一脚本产出）
- 模型/随机性可复现（seed、版本）

# 常见失败
- 不检查数据类型直接算；p 值当结论；图表手工编辑与数据不一致；缺失值静默删除；不记版本。
