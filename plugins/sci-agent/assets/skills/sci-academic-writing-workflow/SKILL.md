# 适用场景
写作类任务：给定材料与要求，产出可交付的学术文本/格式文档。

# 输入契约
- 素材（数据/图表/参考文献/草稿）与要求（期刊模板、字数、语言、引用风格）
- 输出：主文档（可编辑）+ 引用表 + result.json（章节清单/字数/校验）

# 流程
1. 结构：章节骨架 + 每节主张（一句话）；与素材对齐（缺证据的句子删除或标待补）
2. 写作：证据驱动（每段有引用/数据），时态/术语/缩写表全篇一致
3. 格式：模板/引用风格（APA/IEEE/GB）逐项适配；LaTeX 可编译（编译日志>0错误即失败）
4. 自检：抄袭/引用匹配、数字一致、图表编号、字数
5. 交付：主文档 + 编译产物 + 变更记录

# 关键检查
- 每个事实句可溯源；参考文献字段完整（DOI/页码）
- 编译零错误；模板占位符清零
- 长文档目录/编号/交叉引用一致

# 常见失败
- 无证据的断言；引用与正文不匹配；LaTeX 未编译就交付；模板适配只改封面；翻译丢术语一致性。
