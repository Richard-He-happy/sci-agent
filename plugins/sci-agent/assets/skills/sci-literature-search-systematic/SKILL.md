# 适用场景
"检索类"任务：给定研究问题，产出可复现的检索策略、候选文献清单、筛选理由与证据。

# 输入契约
- 研究问题/关键词/时间范围/语言/数据库清单（或允许自行选择并说明）
- 输出：检索式（含字段限定）、命中数、去重后清单、纳排结果、覆盖分析

# 流程
1. 拆问题：PICO/概念组 → 同义词/缩写/拼写变体 → 布尔检索式
2. 执行：至少 2 个来源（示例：OpenAlex/Crossref/PubMed/arXiv），记录检索时间与命中数
3. 去重与筛选：DOI/标题/年份；纳排标准逐条记录
4. 覆盖分析：列出可能遗漏的来源/语言/时间窗，给出补检建议
5. 输出：检索日志（可复现）+ 清单（字段统一）+ result.json

# 关键检查
- 检索式可复现（字段、布尔逻辑、时间窗）
- 每条记录有来源与检索时间；不确定字段置 null
- 不编造 DOI/作者/年份；跨语言检索给出原文与译名

# 常见失败
- 只给关键词列表不给可复现检索式；漏掉同义词；去重把不同文献合并；用模型记忆代替检索；忽视专利/预印本/非英文来源。
