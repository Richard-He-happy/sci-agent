# 适用场景
实验类任务：在预算/设备/安全约束下产出可执行实验方案，并能解释结果与异常。

# 输入契约
- 目标与约束（预算/时长/设备/样本量/安全/伦理）；可用材料清单
- 输出：方案（步骤/参数/时间/风险）、可行性评估、优化建议、比较矩阵、异常解释

# 流程
1. 拆目标：可测量指标 + 成功判据；列出假设
2. 设计：变量/对照/重复/随机化/盲法；参数区间与依据
3. 可行性：设备/耗材/时间/人员/成本逐项核对，缺项给替代
4. 优化：给出参数敏感性排序与推荐值（附区间），说明权衡
5. 解释：结果对照假设；异常给 3 类可能原因 + 排查步骤

# 关键检查
- 每个参数有依据（文献/预实验/物理约束）
- 约束显式（不超预算/设备能力）；安全与伦理合规
- 方案可直接执行（步骤可复现、单位完整）

# 常见失败
- 参数无依据；忽略对照/重复；可行性判断不核对设备；异常只归因"操作失误"。
