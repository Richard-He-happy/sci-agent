# 适用场景
竞赛/真实工作里"读懂材料并结构化输出"的题：文献文档解析、图表解析、结论与数据提取、证据溯源、公式解析、多文档比较、结构化笔记、方法复现、数据清洗、知识图谱。

# 输入契约
- 材料：PDF / 图片 / DOCX / HTML / CSV / JSON；可能无文本层、多栏、多子图、公式
- 任务说明：必做对象、输出字段、字数/条目数限制、引用要求
- 输出：主产物（可编辑格式）+ result.json（status/summary/artifacts/evidence/checks/warnings/errors/metrics/version）

# 流程
1. init：列文件、检测文本层/语言/页数；坏文件标记并降级（OCR/版式解析）
2. extract：按"段落/表格/图注/公式"分块，块级 ID + 页码定位
3. verify：每条结论绑定逐字证据（file:line 或页码+原文）；不可核验标"未验证"
4. build：按契约字段回填；先写 partial 再补全；退出码恒 0

# 关键检查
- 数字与单位：逐字核对原文，禁止推算代替原文
- 图表：图号/标题/坐标轴/图例/误差线分别抽取，缺失记 null 不猜
- 公式：LaTeX 逐符号转写，符号表与正文一致
- 多文档：去重（DOI/标题/年份/作者），冲突结论并列呈现

# 常见失败
- 只给摘要不给定位；定位指向不存在的行；表格列错位；把图注当正文；忽略无文本层 PDF；计数口径不一致（页/段/条）。
